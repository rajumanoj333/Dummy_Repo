# Dummy_Repo

A modern, responsive web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript**.

## Project Structure
- `index.html`: Semantic layout and user interface structure.
- `style.css`: Clean dark-theme styling, CSS variables, and responsive layout.
- `script.js`: Interactive state management and DOM event handling.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/rajumanoj333/Dummy_Repo.git
   ```
2. Open `index.html` directly in any web browser.
